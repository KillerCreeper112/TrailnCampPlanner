# Trip Planner

A full-stack web application designed to help hikers, campers, and backpackers organize and plan outdoor adventures. Users can create trips, manage routes, define camping locations, and keep all trip details in one place.

This project was built to gain hands-on experience with full-stack development using React and Spring Boot.

# Tech Stack

## Frontend
- [React](https://react.dev/)
- [Tailwind CSS](https://tailwindcss.com/)
- [shadcn/ui](https://ui.shadcn.com/)

## Backend
- [Spring Boot](https://spring.io/projects/spring-boot)
- [Spring Security](https://spring.io/projects/spring-security)
- [JWT Authentication](https://github.com/jwtk/jjwt)
- [Spring Data JPA](https://spring.io/projects/spring-data-jpa)
- [MySQL](https://www.mysql.com/)

# Features

## Trip Management
- Create and manage multiple trips
- Set trip name, description, and difficulty
- Define trip start and end dates

## Route Planning
- Create and edit routes for each trip
- Visualize routes on an interactive map
- Add route points and camping locations

## Note Creation
- Create notes for each route, route point, or anywhere on the interactive map

# Why

As someone interested in hiking and backpacking, I wanted to build a tool that could store trip information, routes, and camping locations in one place while giving me experience with React and Spring Boot.
